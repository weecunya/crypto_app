# Django Crypto Tracker 📈



Полноценное веб-приложение на фреймворке **Django** для автоматического отслеживания, сохранения и визуализации курсов криптовалют (BTC, ETH, SOL, XRP, DOGE) с использованием публичного API биржи Binance.

Проект демонстрирует навыки построения монолитных веб-приложений с вынесением тяжелых процессов в асинхронные фоновые задачи, а также работу с брокерами сообщений и контейнеризацией.

##  Стек технологий



* **Backend:** Python 3.13, Django 6.0


* **Database:** SQLite (через Django ORM)


* **Background Tasks:** Celery, Celery Beat, eventlet


* **Message Broker & Result Backend:** Redis 7


* **External API:** Binance API (синхронные запросы через requests)


* **Frontend:** Django Templates, Vanilla JS, Chart.js (для графиков)


* **Testing:** Pytest, HTTPX


* **Infrastructure:** Docker, Docker Compose (разделение на web, worker, beat и redis)



---

##  Design Decisions (Архитектурные решения)



1. **Фоновый парсинг через Celery Beat:**


Чтобы не блокировать основной поток веб-сервера при сборе данных, опросы API биржи вынесены в периодические задачи Celery Beat. Воркер регулярно (раз в 5 минут) получает свежие цены и атомарно сохраняет их в базу данных.


2. **Разделение рендеринга и данных (AJAX-подход):**


При построении графиков страница /chart/ возвращает только легкий HTML-шаблон. Сами данные (массивы времени и цен) подгружаются клиентом асинхронно через вызов fetch к эндпоинту /api-history/, который возвращает подготовленный JSON. Это ускоряет загрузку страницы и является стандартом для современных веб-приложений.


3. **Расширяемая модель пользователя:**


Стандартная авторизация Django переопределена через кастомную модель UserInfo(AbstractUser) с уникальным email. Это закладывает правильный фундамент для будущего масштабирования логики аккаунтов.


4. **Индексирование базы данных:**


В модели CryptoPrice добавлен композитный индекс models.Index(fields=['symbol', '-timestamp']). Поскольку данные всегда фильтруются по монете и сортируются по убыванию времени, этот индекс радикально ускоряет SQL-запросы к таблице при росте объемов данных.

##  Основной функционал



* **Аутентификация:** Регистрация, вход и защищенный профиль пользователя (@login_required).


* **Трекинг криптовалют:** Поддержка Bitcoin, Ethereum, Solana, XRP и Dogecoin.


* **Интерактивные графики:** Визуализация последних 50 записей по выбранному активу с использованием Chart.js.


* **История котировок:** Табличное представление сохраненных цен с форматированием времени и значений.

##  Запуск проекта (Docker)



Проект настроен для быстрого развертывания через docker-compose, который автоматически поднимает веб-сервер, брокер Redis и воркеры Celery.

1. Клонируйте репозиторий:
  
git clone <URL-вашего-репозитория>
cd crypto_project

4. Настройте переменные окружения:
Скопируйте пример файла конфигурации:

cp .env.example .env


6. Запустите контейнеры:

docker-compose up -d --build

После запуска сервисы будут доступны:

* Web UI: http://localhost:8000


* Redis: localhost:6379



Примечание: Чтобы графики начали отображаться, подождите несколько минут, пока Celery Beat выполнит первый сбор данных с Binance.

##  Тестирование



В проекте заложен фундамент для юнит-тестирования с помощью pytest.
Настроен тестовый HTTPX-клиент (conftest.py) для проверки процессов регистрации и логики работы API.

Запуск тестов:
docker-compose exec web pytest -v
